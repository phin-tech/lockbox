# Playpen

Run your agents in OpenShell sandboxes, and decide what they may reach

A Mac app in Rust, on [GPUI](https://gpui.rs), [gpui-kit](https://gpui-kit.com) and
[Typecase](https://git.phin.tech/sam/typecase).

```sh
just run
```

See [DEVELOPMENT.md](DEVELOPMENT.md) for building, checking and releasing.
